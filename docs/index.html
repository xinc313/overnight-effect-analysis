美股「隔夜效应」:收益到底发生在什么时候?

把 SPY(标普 500)与 QQQ(纳指 100)每个交易日的收益拆成「隔夜段」(前收盘 → 次日开盘,即夜盘+盘前)与「日内段」(开盘 → 收盘),用 2000 年以来 6,600+ 个交易日检验:「夜盘到开盘前走势不错」是否在统计上成立、什么条件下更强、以及能否变成可执行的策略。

一、结论先行

  1. 现象真实存在,且高度显著。2000 年至今,QQQ 的全部长期收益都发生在隔夜段:隔夜年化 +11.4%,日内年化 −2.5%。SPY 同样(隔夜 +7.1% vs 日内 +1.2%,日内在统计上与零无异)。这是学术文献中著名的 overnight return effect。
  2. 隔夜段不仅收益高,风险还更低。隔夜段日波动约为日内段的 60–70%,夏普比率 0.67–0.83,对比日内段的 0.01–0.15;纯隔夜持仓的最大回撤约 −33%,而 QQQ 买入持有最大回撤达 −83%。
  3. 但作为独立策略,它对交易成本极度敏感。每天收盘买、开盘卖意味着一年 ~500 次单边交易。单边成本(点差+滑点+佣金)超过约 1.5–2 个基点,优势即被完全吞噬。这正是该效应能长期存在而不被套利消灭的核心原因。
  4. 更现实的用法不是每天翻仓,而是把它作为择时/执行层面的规则:已持仓者没必要为躲避隔夜而日内平仓;加仓倾向收盘时点、减仓倾向开盘时点;以及做条件化策略——「条件化分析」标签页给出了第一批结果:只在前一夜隔夜下跌后持隔夜,交易次数减半、收益保留 90% 以上。

五、为什么会存在?机制与文献

  • 信息发布时点不对称。美股绝大多数财报在盘后/盘前发布,宏观数据(CPI、非农)在开盘前 8:30 ET 发布;重大信息的价格反应大量发生在隔夜段。
  • 隔夜持仓风险溢价。做市商与日内交易者收盘前平仓、不愿承担隔夜跳空风险,愿意为转移这部分风险支付溢价;承担隔夜风险的人获得补偿。
  • 收盘/开盘的流动性结构。收盘竞价卖压(日内客离场)压低收盘价、开盘竞价买压抬高开盘价的微观结构效应。
  • 文献佐证。该效应最早由 Cliff, Cooper & Gulen (2008) "Return Differences between Trading and Non-trading Hours" 系统记录;Lou, Polk & Skouras (2019, JFE) 进一步发现隔夜/日内收益在横截面上有持续的「客群」结构。它在美股大盘指数上已被公开讨论 15+ 年而依然存在——主因即第四节的成本壁垒。

六、如果要往策略方向走:三条务实路径

  1. 执行层优化(最务实,零额外风险)。不改变你的持仓策略,只改变交易时点:计划买入的单子放在收盘竞价(MOC),计划卖出的放在开盘竞价(MOO)。等于免费顺着效应的方向执行,而不是逆着它。
  2. 条件化隔夜。不每天持隔夜,只在信号满足时持有,把交易次数降下来,成本压力同步下降。第一批过滤器(前夜隔夜、前日全日、当日日内、前一周涨跌)已回测完毕,结果见「② 条件化分析」标签页,退出与仓位见「③」、最终形态见「④」。
  3. 低成本工具实现(进阶)。指数期货(ES/NQ 及微型合约)点差 ≈0.1–0.3 bp 且无 ETF 双边佣金,是文献中实现该策略的常用工具,但引入杠杆、保证金和移仓管理,复杂度和风险完全不同,需单独评估。

七、局限与风险(必读)

  • 频繁交易的税务后果。纯隔夜策略产生的全部是短期资本利得,税率按普通所得计;对应税账户这可能比成本更致命。
  • PDT 规则。虽然「收盘买次日开盘卖」不构成 day trade,但衍生的日内操作可能触发 Pattern Day Trader 限制(账户 < $25,000 时)。
  • 肥尾在隔夜。隔夜段平均波动低,但极端跳空(样本内单日 −10.5%)无法止损——持隔夜等于卖出止损的可能性。
  • 制度变迁风险。盘前盘后交易时长在扩展(部分券商已支持 24/5),若隔夜价格发现机制改变,效应可能衰减;2020 年以来日内段收益已明显回升(见第二节表格),两段差距在收窄。

一、问题与方法

总览页说明隔夜段平均更好;这一页回答「什么时候更好」。对今晚的隔夜收益(收盘 → 次日开盘),我们只用决策时点(当日收盘)已知的信息做条件:当日日内涨跌(开盘→收盘)、前一日全日涨跌、前一夜隔夜涨跌、前一周(5 日)涨跌——不存在前视偏差。每个分组报告样本量、胜率、日均收益与 t 值,并用 2000–2012 / 2013–2026 前后半样本检验稳定性,防止数据挖掘。

六、解读与风险

  • 为什么条件化同时改善了收益质量和回撤?因为被剔除的「隔夜上涨后」的夜晚几乎没有溢价(QQQ +1.1bp/晚,统计上为零),留下的夜晚溢价加倍;且连续隔夜暴跌的传染段(2008、2020.3)中策略会在反弹夜自动在场、在追涨夜自动离场。
  • 本质是「接刀」。该策略专挑下跌后的夜晚承接隔夜风险,极端跳空(财报季、宏观冲击的连续 gap)会集中出现在这类夜晚;毛回撤 −17.7% 好于无条件,但单夜 −9% 级别的跳空仍无法止损。
  • 多重检验警示。本页检验了 ~20 个分组;结论只采信在两个标的 × 两个半样本都显著的规律。即便如此,条件化结果的样本外表现通常弱于回测——建议对 2020 年后单独复核(前夜下跌条件在 2013–2026 半样本 t=3.27,仍成立)。
  • 成本与税务与总览页相同:年 ~112 个来回仍是高频操作,短期资本利得税与 PDT 约束同样适用。

二、GBM:方法与它学到了什么

协议:每年 1 月 1 日,用之前的全部历史重新训练梯度提升树(200 棵、深度 3),该年每晚收盘时给「今晚隔夜收益」打一个预测值,超过 2bp(成本线)才持仓——每一个预测都是严格样本外的,全程无前视。约 172 笔/年。

  • 前两名(近 5 日收益 25%、昨夜隔夜 19%)正是手工研究提炼的两大信号——ML 没有推翻任何结论,它把已知信号组装得更好。
  • 当日日内收益占 8.6%,排第 6:单独看它是弱信号(②页结论),但在与 VIX、波动率的非线性交互中有真实贡献——这是引入 ML 的直接收获。
  • 财报月、连涨计数接近 0%,与 ③页的因子裁决一致。

三、穷举背书:96 组合网格搜索

为排除「还有更好的组合没试过」,我们把全部因子开关(进场条件×周末×加仓×波动率×财报月×VIX)共 96 种组合做了网格搜索:训练段(2000–2015)排名,样本外(2016–2026)裁决。结果:

  • 训练段冠亚军 = 样本外冠亚军 = 手工构建的固定模型(样本外夏普 1.03–1.06)。机制推导和暴力搜索收敛到同一答案,信号层已到顶。
  • 训练段前 10 名的样本外夏普均值 0.94(全体 0.74),最优成绩从 1.31 衰减到 1.06——「回测打八折」有了实测依据。
  • 加双重过滤(财报月+VIX)的组合训练段第 3、样本外跌到第 33——过拟合的现形样本。
  • 自适应型组合训练段排 47–50、样本外冲到 7–9——regime 变化被独立确认。

四、正式形态:固定模型(备选方案留档对比)

经权衡,本研究采用固定模型为正式形态——它是全样本(1.15)与样本外(1.06)的双料冠军、96 组合穷举的最优解,规则透明可手工执行。这个选择的实质是押「均值回归会回来」:2025–26 它连续亏损(见下节归因),持有它意味着接受这类年份再次出现,并以第七节的失效红线为兜底。每晚收盘前五步:

  1. 信号 — 昨夜隔夜收益(昨收 → 今开)是否 ≤ 0?否 → 空仓。
  2. 周末剔除 — 明早是否周一?是 → 空仓。
  3. 连跌加仓 — 连跌 1 夜 → 1x;2 夜 → 1.5x;≥3 夜 → 2x。
  4. 波动率刹车 — 仓位 ×(60 夜波动中位数 ÷ 当前 60 夜波动,限 0.5–2),总仓位封顶 2x。
  5. 执行 — 收盘 MOC 买入,次日开盘 MOO 卖出,无论盈亏。

五、为什么需要三代:2025–26 的教训

固定模型 27 年里首次连续两年亏损(2025 −7.6%、2026 YTD −2.8%),归因如下:隔夜效应本身依然健康(2025 隔夜段 +16.1%),但收益全部转移到了「前夜上涨后」的夜晚(+22.9%),固定模型持仓的「跌后夜」反而亏损(−5.9%)——支撑它 25 年的均值回归切换成了动量。我们检验过的所有直觉修法(持有更久、降频、涨后规则、regime 阈值切换)全部被数据否决;通过检验的应对只有两类:数据驱动的自适应/ML 分支、以及模型间分散——两者都已在本页留档,作为第七节红线触发后的切换预案。若还想要 β(不踏空牛市),可用底仓混合:50% 买入持有 + 50% 模型。

六、执行细节与敞口旋钮

  • 每晚流程:收盘前按第四节五步判断,MOC 买入、次日 MOO 卖出;规则完全透明,可手工执行,无需模型打分。
  • 参数纪律:全部参数(1.5x/2x、60 夜、0.5–2、封顶 2x)为事先拍定,不再调优——网格搜索已证明这就是穷举最优,继续调只会过拟合。
  • 敞口旋钮:1x 基准约 10.4%/年、回撤 −17.7%;放大到 2x(保证金上限)约 20%/年、回撤 ~−33%。想要更高绝对收益拧这里,不动信号。
  • 账户与税:约 90 笔/年,全部短期资本利得;2x 需保证金账户(Reg-T 隔夜上限);成本假设 1bp/边,竞价单可达。

七、失效监控:红线与预案(强制项)

选择固定模型的前提是接受这份监控合同——当前滚动 3 年夏普 0.19,处于 26 年历史最低,黄灯已亮:

  • 红线 1:滚动 3 年夏普 < 0 → 立即停用固定模型,预案:切换到本页留档的 50/50 组合或 GBM——切换动作现在写定,届时不做临场判断。
  • 红线 2:信号夜胜率滚动两年 < 50%(历史基线 58%)→ 同上处理。
  • 红线 3:总览页隔夜/日内差距持续为零或倒挂 → 效应根基消失(如 24 小时交易普及),所有形态一并停用。
  • 红线 4:连败超出历史包络(12+ 连败,历史最长 8)→ 市场结构改变信号。

五、退出规则与连败处理

按信号买入后,如果开盘又亏了怎么办?数据的回答分三层:

第一层:扛到收盘没有补偿。信号夜入场、次日开盘亏损的情形(QQQ 历史上 1,232 次),继续扛一个日内段的期望是 −5.0bp(t=−1.11,胜率 49.4%)——开盘割肉并不是卖在地板上,白天不会救你。

第二层:连跌越深,下一夜信号反而越强。连跌 1 夜 → 2 夜 → 3 夜,下一夜隔夜均值 5.5 → 8.8 → 18.9bp(t=3.00)单调走强(连跌 ≥4 夜样本不足,统计不可靠)。所以「又跌了」恰恰是该继续做的时候——这也是连跌加仓(S2)的依据。

七、结论与警示

  • 推荐的最终形态(研究结论,非投资建议):信号 = 前夜隔夜下跌且明早非周一;开盘必卖;连跌加仓 1x/1.5x/2x;仓位再乘以波动率调整系数(60 夜波动中位数 ÷ 当前波动,限 0.5–2x)。基准形态样本外夏普 0.75(S5),叠加周末剔除后全样本夏普升至 1 以上。
  • 参数都是事先拍定的整数/默认值(1.5x、2x、60 夜、0.5–2 上下限),未做网格搜索——这是刻意的:每一次「再调优一下」都在把样本外衰减的账单加厚。
  • 预期管理:训练段(2000–2015)到样本外(2016–2026)所有变体年化普遍衰减 2–4 个百分点,这是隔夜效应整体变弱的大环境(总览页第四节)。把回测夏普再打七折作为实盘预期比较诚实。
  • 执行摩擦未建模:MOC/MOO 竞价单在极端日的成交偏移、加仓造成的资金占用波动、以及税务(全部短期资本利得)都不在回测内。

方法与数据:Yahoo Finance 日频数据(2000-01-03 至 2026-08-13,SPY/QQQ 各 6,693 个交易日,分红再投资的复权价);隔夜收益 = 当日开盘价 / 前日收盘价 − 1,日内收益 = 当日收盘价 / 当日开盘价 − 1;年化为复利口径;t 统计量为对「日均收益 = 0」的单样本检验。条件变量均只使用决策时点已知信息。全部代码见仓库 scripts/。
